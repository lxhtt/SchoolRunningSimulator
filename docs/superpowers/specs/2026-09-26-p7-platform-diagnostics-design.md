# P1-P6 UX 收尾与 P7 平台诊断设计

日期：2026-09-26

## 范围

本设计收尾 RateMock 现有 P1-P6 的交互与验收表面，并加入安全边界内的 P7 平台诊断。P7 只验证设备能力、权限、真实传感器回调和应用内事件时序；不实现系统级传感器注入、隐藏 mock 来源、Xposed/LSPosed、第三方应用检测绕过或校园跑平台兼容承诺。

## P1-P6 UX 目标

### 主导航与状态

保留“模拟 / 记录”两个主区域，增加“诊断”入口。每个区域顶部显示当前用途与数据来源：模拟为合成数据，记录为真实观测，诊断为设备/回调检查。运行状态使用明确文字和语义颜色，同时保留可访问的文本说明。

模拟页面采用表单 -> 自检 -> 运行 -> 结果的顺序。开始按钮只在自检允许时启用；运行时底部固定控制栏提供暂停/继续和停止；结束后把结果、波形复核、只读诊断和导出集中在同一结果区。预设只填表单，不启动服务。

记录页面采用权限 -> 配置 -> 开始的顺序。开始失败显示具体原因；记录状态来自持久化状态而非心跳。停止中、已停止、失败和可导出状态分别显示，导出按钮只在严格资格校验通过后启用，并在导出前再次校验。

### 响应式与可访问性

使用现有 Compose 语义组件和 8dp 间距节奏。固定底栏遵守 safe drawing padding，滚动内容留出底部空间。按钮保持至少 48dp 高度，滑块旁显示当前数值，错误不只使用颜色。大字体下文本允许换行，横屏和窄屏不依赖固定宽度。诊断列表提供设备能力的文字状态和操作建议。

## P7 平台诊断（首期已实现）

### 诊断内容

诊断页显示 `TYPE_STEP_DETECTOR`、`TYPE_STEP_COUNTER` 和加速度计是否存在，以及活动识别权限。仅在用户主动点击开始且诊断页保持打开时，注册本应用的逐步和计数器监听；停止或离开页面即注销。质量摘要记录事件数、首末时间、最大间隔、非递增时间和计数器回退。加速度计只检测能力，不采集波形。无事件不等于设备不支持，更不代表第三方平台的接收行为。

### 数据边界

事件最多在内存中保存 10,000 条，切换页面或进程退出即清空；不持久化到 `recordings` 或 `simulations`。用户通过文档选择器主动导出 JSON 时，报告只包含来源 `real_diagnostic`、设备 SDK、相对时钟时序和质量摘要，不包含 GPS 坐标或个人轨迹。应用内 P5 只读回放继续作为自有合成事件接收/验证器，与本页真实传感器诊断明确分离。

### 实现边界与下一阶段

纯 Kotlin 报告负责事件时间递增、计数器回退和间隔分布，Android 页负责权限/能力与真实回调采样。第二阶段新增的是纯文件自有测试接收端，不创建 mock provider 或跨应用数据入口；本页不宣称息屏数据连续性或校园跑平台兼容性。

## P7 自有测试接收端（第二阶段）

使用 `:receiver-ui` Android 库共享测试接收屏幕，分别由 RateMock 内“测试接收”页和可独立安装的 `:receiver` App 调用。两者只通过系统文档选择器主动打开 JSON；没有导出的接收组件、后台服务或第三方包通信。独立 App 不请求位置、活动识别或网络权限。

输入格式 `ratemock.local-replay.v1`：根对象声明 `schema` 和 `provenance=simulation` 或 `replay`，`events` 数组包含 `position`（本地 east/north 米）、`step_detector` 或 `step_counter` 事件及 session_id、sequence、time_s。拒绝超过 1 MiB 或 10,000 条的文件、未知事件种类、缺字段、非有限数值和混用来源；经 `LocalReplayValidator` 报告时间/序号/累计计数和位置跳变。解析错误明确呈现在界面，不保留文件 URI 或原始内容。附内置可运行样本供无平台材料时完成接收链路验证；报告不代表 Android 系统传感器或校园跑平台接收结果。

同一共享组件避免应用内和独立 App 的解释分歧。模拟历史提供用户主动选择目标的测试事件 JSON 导出：仅把已有本地位置样本转为 position 事件，超出接收限制时拒绝导出，不伪造逐步传感器事件。CI 同时 lint/assemble 两个 App；独立 APK 单独上传，不能与主 APK 混淆。真机需分别验证文件选择、拒绝畸形输入和退出后无残留记录。

## 验收

- 离线检查验证 P7 不含注入 API、诊断不会写入真实/模拟记录目录、资源引用完整。
- JVM 测试覆盖空会话、能力缺失、递增事件、时间回退、计数器回退和最大间隔。
- CI 负责 Kotlin/JUnit、Android lint 和 APK 构建。
- 真机验证覆盖窄屏、横屏、大字体、深浅色、权限拒绝、前后台和息屏对照；不把结果外推到其他 ROM 或校园跑平台。
